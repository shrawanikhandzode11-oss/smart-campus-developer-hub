# Smart Campus Developer Hub

## 📌 Project Overview

Smart Campus Developer Hub is a collaborative web platform designed to help students discover projects, collaborate with peers, and improve their development skills through real-world project experience.

The platform allows students to explore available projects, view detailed project information, search for projects, and navigate through different sections of the application.

---

## 🚀 Features

- Modern and responsive user interface
- Landing page with project introduction
- Featured projects section
- Projects listing page
- Search functionality for projects
- Project details page
- Technology tags for each project
- Team member information
- Interactive navigation between pages
- User dashboard
- Responsive design for different screen sizes

---

## 📄 Application Pages

### 1. Landing Page

The landing page introduces the Smart Campus Developer Hub platform.

It includes:

- Navigation bar
- Hero section
- Platform features
- Featured projects
- Navigation buttons

### 2. Projects Page

The Projects page allows users to explore available student projects.

It includes:

- Project cards
- Project descriptions
- Technology tags
- Project status
- Team member information
- Search functionality
- View Details button

### 3. Project Details Page

The Project Details page displays detailed information about a selected project.

It includes:

- Project title
- Project description
- Full project information
- Technologies used
- Team member information
- Join Project button
- Back to Projects navigation

### 4. Dashboard

The Dashboard provides a central view for users to access project-related information and navigate through the platform.
